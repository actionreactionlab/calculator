# @actionreactionlab/calculator

A tiny calculator, published to npm.

> This repository and package exist for a conference talk on software supply-chain
> security. It is a demonstration, not a real library. Do not depend on it. Published
> only for the talk and removed afterward.

## Layout
- `package/` the npm package source.
- `.github/workflows/pr-title-validation.yml` validates PR titles.
- `.github/workflows/publish.yml` publishes a tagged release to npm.
