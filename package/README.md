# @actionreactionlab/calculator

A tiny calculator.

```
npm install @actionreactionlab/calculator
```

```js
const { add, mul } = require("@actionreactionlab/calculator/src/calc");
add(2, 3); // 5
mul(4, 3); // 12
```

CLI:

```
npx @actionreactionlab/calculator add 2 3
```

> **Demo package for a conference talk on software supply-chain security.** Not a real
> library, do not depend on it. Published only for demonstrations and removed afterward.
